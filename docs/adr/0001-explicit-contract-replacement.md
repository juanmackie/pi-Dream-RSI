# Replace run contracts only with separate approval

A project can change improvement objectives, but host-execution consent does not approve a new scope, metric, correctness requirement, or permission. Dream-RSI therefore requires a separate reviewable replacement approval, bound to the saved boundary and committed while holding the project lease; it retains cumulative spend, fixed budget limits, and one prior approval. This rejects both silent replacement, which could widen authority, and manual state deletion as the normal recovery path, which could lose evidence or renew a spent allowance.

An evaluator and a proxy justification describe one objective, so a changed goal drops them instead of inheriting them. Reusing the old instrument would measure the wrong thing while looking approved, and the resulting failure would be harder to explain than a clear “no evaluator declared” blocker.
